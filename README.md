# Link3 Frontend

## О проекте
Данный репозиторий — пример проекта на Nuxt, в котором я разработал около 60% компонентов.
Данный проект не работает! А лишь служит ПРИМЕРОМ моего последнего проекта.

## Также в рамках проекта:
- Реализовал локализацию с использованием i18n.
- Адаптировал компоненты Nuxt UI под дизайн проекта.
- Настроил Tailwind CSS под требования проекта: цветовую палитру, типографику и стили компонентов.

## Технологии

- **Nuxt 3.17.3** - современный Vue.js фреймворк
- **Vue 3.5.13** - прогрессивный JavaScript фреймворк
- **TypeScript 5.8.3** - типизированный JavaScript
- **Pinia 3.0.2** - управление состоянием
- **Nuxt UI 3.3.0** - UI библиотека с Tailwind CSS
- **@nuxt/image 1.10.0** - оптимизация изображений
- **@nuxt/icon 1.15.0** - система иконок
- **Swiper 11.2.10** - слайдер компоненты
- **Vue Advanced Cropper 2.8.9** - редактирование изображений
- **SortableJS 1.15.6** - drag-and-drop функциональность
- **Zod 3.24.4** - валидация схем
- **nuxt-qrcode 0.4.6** - генерация QR-кодов
- **Husky 9.1.7** - Git hooks для качества кода
- **ESLint 1.3.1** - линтинг кода
- **Sass 1.91.0** - препроцессор CSS

## Структура проекта

```
├── assets/           # Статические ресурсы (стили, шрифты, иконки, изображения)
├── components/       # Vue компоненты
│   ├── modals/       # Модальные окна
│   ├── onboarding/   # Компоненты онбординга
│   ├── shared/       # Общие компоненты (формы, инпуты, модалы)
│   ├── themes/       # Компоненты тем оформления
│   └── user/         # Пользовательские компоненты
├── composables/      # Vue композабл функции
├── constants/        # Константы приложения
├── errors/           # Обработка ошибок
├── layouts/          # Макеты страниц
├── middleware/       # Промежуточное ПО
├── pages/            # Страницы приложения
│   ├── admin/        # Административная панель
│   ├── auth/         # Страницы авторизации
│   ├── password-reset/ # Сброс пароля
│   ├── photo/        # Управление фотографиями
│   ├── profile/      # Профиль пользователя
│   └── user/         # Публичные страницы пользователей
├── plugins/          # Плагины Nuxt
├── public/           # Публичные статические файлы
├── server/           # Серверные роуты
├── stores/           # Pinia хранилища
│   └── types/        # Типы для хранилищ
├── types/            # TypeScript типы
└── .husky/           # Git hooks для качества кода
```

## 🛠️ Инструменты разработки

### Качество кода

- **ESLint** - статический анализ кода
- **Husky** - Git hooks для автоматической проверки
- **lint-staged** - проверка только измененных файлов
- **TypeScript** - строгая типизация

### Стилизация

- **Sass** - препроцессор CSS
- **Tailwind CSS** - utility-first CSS фреймворк
- **CSS переменные** - кастомизируемые темы
- **Адаптивные breakpoints** - мобильная оптимизация
